# Copilot для macOS и Windows

Форк [Magerko/copilot](https://github.com/Magerko/copilot): порт на macOS (Apple Silicon) и несколько новых функций.
Автор оригинала — [Magerko](https://github.com/Magerko), лицензия MIT сохранена.

Слушает разговор, распознаёт речь локально, замечает вопросы и показывает короткий
ответ в небольшом оверлее — с опорой на загруженные документы. macOS и Windows.

## Что добавлено в форке
- **macOS**: сборка под Apple Silicon, whisper.cpp из Homebrew на Metal, системный звук через ScreenCaptureKit.
- **Claude по подписке**: ответы через официальный Claude Code CLI и ваш вход в него, без API-ключа.
- **Пул API-ключей**: несколько ключей одного провайдера по очереди, при лимите запрос сразу уходит на следующий.
- **Решение задачи с экрана**: одна клавиша снимает экран; модель пишет эталонное решение, разбирает видимый код и предлагает вопросы автору.
- **Работа из оверлея**: кнопки, тумблер автоответа, главное окно сворачивается на время сессии.
- **Быстрее и экономнее**: заранее запущенные процессы Claude, меньше лишних обращений к GPU, более чуткое распознавание тихой речи.

## Возможности
- Локальное распознавание речи (whisper.cpp): аудио не уходит в сеть и не пишется на диск.
- Модель ответов на выбор: локальная (Ollama, LM Studio) или облачная по ключу
  (OpenAI, Anthropic, Gemini, AnyModel, любой OpenAI-совместимый) или Claude по подписке.
  Ключи — в DPAPI на Windows и в Связке ключей на macOS.
- Ответы опираются только на загруженные документы; не найденное помечается `[нет в резюме]`.
- Снимок выделенной области экрана → vision-модель или локальный OCR.
- Оверлей не забирает фокус, автоподстройка высоты, регулируемая прозрачность.
- Окна можно исключить из захвата экрана (SetWindowDisplayAffinity на Windows,
  NSWindowSharingNone на macOS). Это не гарантия: на macOS 15+ программы на ScreenCaptureKit флаг игнорируют.
- Сворачивание в трей, аварийная остановка, продолжение прошлой сессии.
- Учёт расхода по платным моделям и лимиты в настройках. Офлайн-режим блокирует внешние вызовы.
- Без аккаунта и своего сервера.

## Первый запуск
1. Язык → звук (микрофон и системный звук) → распознавание (загрузка ≈ 160 МБ).
2. Модель: [Ollama](https://ollama.com) подхватывается сама, иначе — провайдер и ключ.
3. Профиль и документы (PDF/DOCX/TXT).

На macOS распознавание ставится через Homebrew (`brew install whisper-cpp`), а для «Claude по подписке» нужен
[Claude Code](https://claude.com/claude-code): `brew install --cask claude-code`. При первом запуске macOS спросит доступ
к микрофону и записи экрана.

| Аварийная остановка | `Ctrl+Alt+Backspace` | `⌃⌥⌫` |

## Для разработчиков
```powershell
npm install
npm test
npm run dev       # разработка
npm run dist      # установщик Windows в release/
```
На macOS:
```bash
npm install
npm run install:mac   # сборка, подпись и установка в /Applications
```
macOS привязывает разрешения к подписи. Без самоподписанного сертификата «Copilot Dev» в связке ключей
`scripts/sign-mac.sh` подпишет приложение ad-hoc, и разрешения придётся выдавать после каждой сборки.

Архитектура и решения — в `docs/pipeline/`.

## Границы использования
Записывать разговор и использовать AI-подсказки можно только там, где это разрешено, и участников нужно предупреждать.
Приложение не обходит прокторинг и средства контроля.
